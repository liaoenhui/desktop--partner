# 银狼 LV.999 桌宠

## 在另一台电脑直接使用

[下载 v2.6.5 Windows x64 便携包](https://github.com/liaoenhui/desktop--partner/raw/refs/heads/main/downloads/SilverWolfPet-v2.6.5-Windows-x64.zip)

完整解压后运行 `SilverWolfPet.exe`，保留同目录的 `assets` 文件夹。若旧版正在运行，先从托盘退出。无需安装开发工具。

[换电脑与源码构建说明](docs/another-computer.md) · [下载文件与校验值](downloads/)

新电脑的 Codex 需单独登录；桌宠监测新电脑的本机任务，登录信息和旧电脑个人设置不随本仓库同步。

Windows 10/11 x64 桌宠。默认形象基于用户确认的银狼 LV.999 Q 版概念稿。基本互动离线运行；Codex 额度功能使用本机已登录的 Codex 联网查询。新版运行 `dist/SilverWolfPet-v2.6.5/SilverWolfPet.exe`，请保留同目录的 assets 文件夹。启动新版前，在旧版托盘菜单中退出旧版；各版共用设置，仅允许运行一个桌宠。

## v2.6.3 轻量随身入口与游戏免打扰

- 跟随模式去掉小黄豆外圈，只保留独立小黄豆和上方读数。数字采用 Segoe UI，百分号缩小，轻微深色阴影提高浅色背景上的可读性。右侧停靠仍保留原有侧栏外形。
- 不再以窗口是否铺满屏幕判断免打扰。仅当前前台程序匹配游戏列表时隐藏桌宠和额度终端，切回浏览器、视频、办公软件后恢复。窗口化游戏也适用；后台运行的游戏不会影响正在使用的浏览器。
- 设置中增加游戏列表，可添加实际游戏 .exe 或移除条目。默认包含星穹铁道、原神、绝区零、CS2、英雄联盟、无畏契约的常见程序名；不保证自动识别所有游戏。常见浏览器有明确排除规则。无法读取或确认程序身份时不隐藏。
- 普通全屏浏览器不再触发 Codex 通知延后；游戏期间仍沿用“免打扰期间仍允许 Codex 托盘通知”选项。手动隐藏、今日静音和关闭任务提醒等用户设置继续生效。
- 自检覆盖游戏匹配、浏览器排除、自定义完整路径、未知程序、游戏隐藏后切回浏览器恢复、解除通知免打扰及保留手动隐藏；额度与桌宠回归检查通过。无外圈入口完成离屏渲染检查，本轮桌面截图工具异常，未完成真实悬停复测；未实测所有游戏与混合 DPI 多屏。
- 无边框与独占全屏呈现机制不同，不以“游戏必定覆盖置顶桌宠”为前提，保留可关闭的游戏免打扰。参考：https://learn.microsoft.com/en-us/windows/win32/direct3ddxgi/for-best-performance--use-dxgi-flip-model
- 旧版发行包及 v2.4.8 稳定备份继续保留。

## v2.4.3 主题界面、触碰修复与免打扰

- **主题界面**：回应气泡采用深紫渐变、青蓝标识、圆角切角按钮，自定义悬停、按下与键盘焦点样式；设置与状态面板使用深色主题。带按钮的气泡按实际内容高度留出空间。
- **触碰修复**：身体轻点改为独立点头动作，不再复用扶镜；头发、脸颊、护目镜仍有各自回应。切换部位立即刷新人物帧，打断原来的动作和输入联动，不再短暂显示上一部位的动作。气泡标明当前识别部位和轻触／长按／连点。鼠标点击不会触发键盘联动。
- **全屏免打扰**：默认开启，每约半秒检查前台窗口是否覆盖其所在显示器整屏。自动隐藏桌宠；离开全屏后恢复，手动隐藏的桌宠不会被强行显示。普通作息提醒延后至桌宠重新可见且空闲时，休息提醒继续按使用计时处理。默认 Codex 通知也延后，设置可允许免打扰时仍弹 Codex 托盘通知。未全屏的视频不触发；某些覆盖整屏的无边框最大化窗口也会被识别为全屏。
- **快捷键**：Ctrl + Alt + H 显示／隐藏桌宠；Ctrl + Alt + P 开关鼠标穿透。全屏时可用显示快捷键临时找回，退出全屏后恢复自动免打扰规则。冲突导致注册失败时，在设置中显示状态，可改用托盘操作；退出时释放快捷键。
- **鼠标穿透**：开启后点击会落到桌宠后面的应用，角色和气泡按钮不再拦截；可通过托盘菜单、设置窗口或快捷键关闭。开关保存在本机，设置与托盘本身不穿透。

版本号显示于窗口标题、设置和托盘提示中。升级时必须先退出旧版，否则单实例机制仍会保留旧版运行；开机自启动也应在新版设置中更新。

验证：自动测试涵盖跨部位快速切换与帧刷新、原有触碰和提醒逻辑、全屏几何判定、免打扰开关／手动覆盖、Windows 原生穿透样式的启用／关闭及其他样式保持。另使用实际鼠标点击验证身体、脸颊、护目镜和头发的分别回应。全屏游戏、全屏视频及快捷键冲突的实际场景尚未逐项实测。

## v2.4 可回应的提醒与日常陪伴

- **对话选项**：作息、休息和可见时的 Codex 提醒提供「知道了」「10 分钟后」「今天不提醒」。延后时间和当天静音保存在本机，重启仍有效；静音针对当前提醒类别（Codex 提醒为一类，每条作息提醒分别处理）。设置中可恢复当天静音。气泡 25 秒后自动收起；延期消息在程序运行且桌宠可见、空闲时补发。哈欠台词附带「好啊，陪你一会儿」「等我忙完」，配合回应动作，此版本尚无可游玩的小游戏。
- **连续使用提醒**：默认累计 60 分钟活跃使用后提醒喝水、活动；设置可选 15、30、45、60、90、120、180 分钟。超过 1 分钟没有输入时暂停累计，离开满 5 分钟或检测到长时间计时中断后重计；不是医学上的久坐检测，看视频等无输入活动不会持续计入。计时从桌宠本次启动开始，隐藏时仍计时，提醒等重新显示后再弹。
- **状态面板**：右键桌宠或托盘 → 状态面板。显示本地时间、电池／供电状态、本段活跃使用时间、提醒间隔和 Codex 额度。无电池或未知状态不会误显示成 0%。面板打开时约每秒刷新，Codex 数据沿用约每分钟的读取周期。
- **键盘联动**：仅键盘按键活动会触发操作动作与全息键盘闪光，密集操作加快动画，停下后收起。使用现有操作动作和程序绘制的键盘，不新增人物立绘。只临时计数操作事件，不读取、保存或上传输入文字；设置关闭时卸载输入钩子。受 Windows 桌面会话和权限限制，锁屏或部分受保护窗口中的输入可能无法联动。
- **离开／回来**：默认无输入 5 分钟后打盹，保持闭眼状态；恢复操作时伸懒腰并欢迎回来。关闭此功能不影响休息计时；隐藏状态不会自动弹出角色。

这三项自动行为在设置中各有独立开关。气泡按钮会实际接收鼠标点击，透明区域仍可穿透；多项通知按照原有优先级显示。v2.4 自动测试覆盖活跃计时、休息重置、休眠间隔、延后／静音按钮、持续打盹，以及原有动作、Codex 和自启动功能。`qa/replies.png` 为真实 WPF 气泡渲染检查图；真实键盘联动与混合 DPI 多屏仍建议在日常使用中验证。

## v2.3 Codex 额度与任务结束提醒

设置中新增两个独立开关，默认开启：

- Codex 5 小时和周额度：剩余严格低于 50%、20%、5% 时提醒，0% 时提示耗尽。一次跨过多个档位只提示最紧急的档位；每个额度窗口按重置时间去重，重启不重复。首次运行若已低于阈值，会提醒一次。设置面板显示剩余百分比、重置时间和最近成功读取时间；读取失败明确显示不可用，不按零额度处理。
- 本机 Codex 每轮任务运行结束：显示二创气泡并配上扶镜动作。隐藏桌宠时使用 Windows 托盘通知（可能受系统通知设置或勿扰模式影响）。取消事件不报完成，不补发桌宠启动之前结束的历史任务。提示里的尾号对应本地任务 ID；“运行结束”不保证任务成功，请回 Codex 验收结果。

额度约每 60 秒读取一次；本地任务事件约每 2 秒检查一次，额度连接等待时可能延迟约 20 秒。退出或休眠期间不提醒。桌宠可见时提醒排队显示，最多保留 30 条；已有气泡和拖拽结束后再显示。任务范围是当前电脑 Codex 的本地会话，不包含 ChatGPT 网页聊天、其他电脑和云端任务。

需要安装并登录 Codex 桌面版或 CLI。程序在 PATH 和当前用户的 OpenAI/Codex/bin 中自动寻找 codex.exe，尊重 CODEX_HOME。通过官方 [App Server 接口](https://learn.chatgpt.com/docs/app-server)初始化后只调用 account/rateLimits/read，不发送模型请求、不购买额度、不修改登录或用户的通知钩子配置，也不需要另购 API Key。这里的额度是 Plus 账户下的 **Codex 额度**，不是 ChatGPT 网页各模型聊天额度。

任务结束通过只读增量解析 CODEX_HOME/sessions 中的 task_complete 事件识别，不存储提示词或回复正文，不把会话内容上传给第三方。这是本地日志兼容适配；未来 Codex 日志格式变化可能需要更新。额度提醒记录保存于 %LOCALAPPDATA%/SilverWolfPet/codex-alerts.json，开关仍在 settings.json。关闭两个开关后不查询账户额度；桌宠基础互动正常工作。

验证：`SilverWolfPet.exe --self-test` 检查阈值、跨档去重、重置、重启去重、空数据、增量半行、历史过滤和关闭提醒；`--codex-check` 只读连接账户，将不含身份凭据的额度摘要写到 qa/codex-connection.txt。连接测试应在正常登录的 Windows 用户环境运行。

## v2.2 动作台词与定时提醒

打哈欠、伸懒腰、打游戏、音游等随机待机动作会配上对应的二创台词，同一动作的台词尽量不连续重复。右键动作预览也会显示配套气泡。例如哈欠时说「好无聊啊，要陪我来一局吗？」。设置中可分别关闭「动作时显示台词气泡」和「定时问候与作息提醒」。动作台词开关控制自动待机及动作预览，主动点击和拖动的原有交互反馈保留。

默认提醒（电脑本地时间，每天）：

| 时间 | 内容 |
| --- | --- |
| 09:00 | 上线与今日任务 |
| 12:00 | 午饭、补充体力 |
| 15:00 | 起身喝水、休息 |
| 18:00 | 喂，到点下班了。今天的进度先存个档。 |
| 22:00 | 收尾，别拖到半夜 |
| 00:00 | 还不睡，准备和我通宵打游戏吗？……算了，先存档，明天再来。 |

每条提醒每天只显示一次，记录保存在本机设置中，重启不会重复。当桌宠可见且空闲时显示；拖拽、已有气泡、打开菜单或设置时稍后再尝试。有效窗口为指定时间起的 5 分钟，超时不补发；隐藏桌宠不弹提醒，也不强行显示窗口。需要程序正在运行，休眠或退出时不提供系统通知。随机动作台词不会覆盖定时提醒，主动交互可打断提醒。

可编辑角色包 `pet.json` 自定义：`actionLines` 按动作名提供台词数组；`reminders` 每项包含唯一 `id`、24 小时制 `time`、可选 `action` 和 `lines` 台词数组。时间示例 `18:00`，单条台词最多 200 字，每天最多 32 条提醒。修改后重启桌宠或重新导入素材包生效。

## v2.1 开机自启动

右键桌宠 → 设置与自定义形象 → 勾选「开机自启动（登录 Windows 后）」。默认关闭，开启后下次登录 Windows 时启动桌宠；取消勾选即可关闭。无需管理员权限。

请先把解压后的程序文件夹放到固定位置再开启。移动文件夹或换用新版后，打开新位置的设置；若提示关联了其他版本，点击「自启动改用当前版本」。也可关闭后重新开启。如果曾在 Windows 任务管理器中禁用桌宠启动项，需要在那里允许启动。

实现使用当前用户启动文件夹中的 `SilverWolfPet.lnk`，目标为当前程序，参数为 `--autostart`，工作目录为程序文件夹。只在用户操作开关时修改启动项。已有桌宠运行时，自启动实例静默退出，不弹重复启动提示。卸载或删除程序前请先取消勾选。

快捷方式实现参考 Microsoft 文档：https://learn.microsoft.com/en-us/troubleshoot/windows-client/admin-development/create-desktop-shortcut-with-wsh 。

## 自定义素材包

复制 `assets/default` 到自己的文件夹，替换 PNG 并编辑 `pet.json`，从设置中导入。素材包通过路径引用，导入后不要删除或移动文件夹。图片背景应真正透明，不是白底或棋盘格。仅支持 PNG，最长边 2048，单文件不超过 16 MB，总动画帧数不超过 120。导入失败保留现有形象；启动时素材丢失则恢复默认。

```json
{
  "name": "我的桌宠",
  "image": "pet.png",
  "fps": 8,
  "clickLines": ["你好呀！"],
  "idleLines": ["休息一下。"],
  "animations": {
    "idle": ["idle/01.png", "idle/02.png"],
    "click": ["click/01.png", "click/02.png"],
    "drag": ["drag/01.png"],
    "land": ["land/01.png"],
    "sleep": ["sleep/01.png"]
  }
}
```

所有帧使用相同画布尺寸和脚底位置；缺少某个动画则使用基础立绘。素材包不能引用其文件夹之外的图片。台词均为二创文案。

### 图集与动作时间轴

新版额外支持 `atlases` 和 `clips`，默认包即为完整示例。图集按行从 0 开始编号；`frames` 指定播放顺序，`milliseconds` 逐项指定停留时间，`loop: false` 表示播到最后一帧后保持，由动作状态决定何时结束。支持 `blink`、`click`、`headpat`、`annoyed`、`drag`、`land`、`yawn`、`stretch`、`game`、`rhythm`，兼容旧版 `animations`。单张图集最长边 4096，总图集像素不超过 3200 万。

```json
{
  "atlases": { "faces": { "file": "faces.png", "columns": 3, "rows": 2 } },
  "baseAtlas": "faces",
  "baseFrame": 0,
  "clips": {
    "blink": { "atlas": "faces", "frames": [1,0], "milliseconds": [110,80], "loop": false }
  }
}
```
